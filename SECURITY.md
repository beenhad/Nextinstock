# Security

If you find a way to expose credentials or buyer data, change a listing without the seller's approval, or otherwise put a shop at risk, please [report it privately through GitHub](https://github.com/beenhad/Nextinstock/security/advisories/new). Do not open a public issue for a security problem.

Describe the impact and steps to reproduce with fake data. Do not include working keys, webhook URLs, buyer details, or a live shop's data. If a credential has already leaked, revoke or rotate it with eBay or Discord first.

Security fixes are made against the current `main` branch; older commits are not maintained separately. For ordinary bugs and feature ideas, use [Issues](https://github.com/beenhad/Nextinstock/issues/new).
